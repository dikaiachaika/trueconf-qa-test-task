# Проверка навигации интерфейса

TC-15 Отображение меню панели администратора

Шаги:
1. Авторизоваться в системе
2. Посмотреть левую часть интерфейса

Ожидаемый результат:
Отображается меню навигации.


TC-16 Переход в раздел пользователей

Шаги:
1. Авторизоваться
2. Нажать пункт меню "Пользователи"

Ожидаемый результат:
Открывается страница пользователей.


TC-17 Переход между разделами

Шаги:
1. Перейти в раздел пользователей
2. Перейти в раздел настроек
3. Вернуться обратно

Ожидаемый результат:
Разделы открываются без ошибок.


TC-18 Выход из системы  
Шаги:
1. Нажать кнопку выхода

Ожидаемый результат:
Открывается страница входа.

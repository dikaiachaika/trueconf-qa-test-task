# Проверка валидации форм

TC-19 Проверка обязательных полей

Шаги:
1. Перейти в раздел "Создать пользователя"
2. Оставить поля пустыми
3. Нажать "Сохранить"

Ожидаемый результат:
Система отображает сообщение о необходимости заполнить поля.


TC-20 Проверка минимальной длины пароля

Шаги:
1. Перейти в раздел создания пользователя
2. Ввести логин
3. Ввести короткий пароль
4. Нажать "Сохранить"

Ожидаемый результат:
Система сообщает, что пароль слишком короткий.


TC-21 Проверка допустимых символов логина

Шаги:
1. Перейти в создание пользователя
2. Ввести специальные символы в логин
3. Нажать "Сохранить"

Ожидаемый результат:
Система отображает сообщение об ошибке.


TC-22 Проверка длинного логина

Шаги:
1. Ввести очень длинный логин
2. Нажать "Сохранить"

Ожидаемый результат:
Система корректно обрабатывает значение.


TC-23 Проверка сохранения данных

Шаги:
1. Создать пользователя
2. Обновить страницу браузера
3. Вернуться в список пользователей

Ожидаемый результат:
Созданный пользователь остается в системе.

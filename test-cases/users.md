# Тестирование управления пользователями

TC-07 Открытие раздела пользователей

Шаги:
1. Авторизоваться в веб-панели администратора
2. В левом меню выбрать раздел "Пользователи"

Ожидаемый результат:
Открывается страница со списком пользователей.


TC-8 Создание нового пользователя

Шаги:
1. Перейти в раздел "Пользователи"
2. Нажать кнопку "Добавить пользователя"
3. Ввести логин
4. Ввести пароль
5. Нажать кнопку "Добавить"

Ожидаемый результат:
Новый пользователь появляется в списке пользователей.


TC-9 Создание пользователя с пустым логином

Шаги:
1. Перейти в раздел "Пользователи"
2. Нажать "Добавить пользователя"
3. Оставить поле логина пустым
4. Ввести пароль
5. Нажать "Добавить"

Ожидаемый результат:
Система отображает сообщение об ошибке.


TC-10 Создание пользователя с пустым паролем

Шаги:
1. Перейти в раздел "Пользователи"
2. Нажать "Добавить пользователя"
3. Ввести логин
4. Оставить поле пароля пустым
5. Нажать "Добавить"

Ожидаемый результат:
Система сообщает об ошибке.


TC-11 Создание пользователя с уже существующим логином

Шаги:
1. Перейти в раздел "Пользователи"
2. Нажать "Создать пользователя"
3. Ввести логин существующего пользователя
4. Ввести пароль
5. Нажать "Сохранить"

Ожидаемый результат:
Система сообщает, что пользователь уже существует.


TC-12 Редактирование пользователя

Шаги:
1. Перейти в раздел "Пользователи"
2. Выбрать пользователя из списка
3. Изменить данные пользователя
4. Нажать "Сохранить"

Ожидаемый результат:
Данные пользователя обновляются.

TC-13 Удаление пользователя

Шаги:
1. Перейти в раздел "Пользователи"
2. Выбрать пользователя
3. Нажать кнопку "Удалить"
4. Подтвердить удаление

Ожидаемый результат:
Пользователь удаляется из списка.


TC-14 Поиск пользователя

Шаги:
1. Перейти в раздел "Пользователи"
2. Ввести логин пользователя в поле поиска
3. Нажать поиск

Ожидаемый результат:
Отображается найденный пользователь.

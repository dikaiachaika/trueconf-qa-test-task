# BUG-02 Кнопка "Назад" не работает после создания пользователя

## Описание
После создания нового пользователя кнопка "Назад" на странице добавления пользователя перестает работать.

## Предусловие
Администратор авторизован в веб-панели сервера.

## Шаги воспроизведения
1. Перейти в раздел "Пользователи".
2. Нажать "Добавить пользователя".
3. Заполнить поля логина и пароля.
4. Нажать кнопку "Добавить".
5. Нажать кнопку "Назад".

## Фактический результат
Кнопка "Назад" не работает. Пользователь остается на странице добавления пользователя.

## Ожидаемый результат
Происходит переход на страницу со списком пользователей.

## Окружение
Server: TrueConf Server Free

# BUG-01 Кнопка "Главная" вызывает ошибку соединения

## Описание

При нажатии на кнопку "Главная" на странице авторизации администратора происходит ошибка соединения.

## Шаги воспроизведения

1. Перейти по адресу http://localhost
2. Открыть страницу Вход для администратора 
3. Нажать кнопку "Главная" в правом верхнем углу

## Фактический результат

Браузер отображает сообщение: "Попытка соединения не удалась".

## Ожидаемый результат

Происходит переход на главную страницу сервера.

## Окружение

Server: TrueConf Server Free  
OS: Windows  
Browser: Mozilla Firefox  
Адрес: http://localhost

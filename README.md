# Тестовое задание QA – TrueConf Server
В данном репозитории представлены тест-кейсы для тестирования веб-интерфейса сервера TrueConf.

## Окружение тестирования:
Сервер: TrueConf Server   
ОС: Windows  
Браузер: Mozilla Firefox  
Адрес сервера: http://localhost

## Структура проекта:

test-plan.md – план тестирования

test-cases/ – тест-кейсы:
- аутентификация
- управление пользователями
- навигация
- проверки валидации

screenshots/ – скриншоты:
- список пользователей сервера
- вход в десктопный клиент
- вход в мобильный клиент


bug-roports/ - найденные ошибки
